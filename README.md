# NEXA · Hecho para ti 💜

Página web dedicada a **Ariadna Jazmín García Segura** — Quality Assurance del **Equipo 8 · NEXA** — con motivo del proyecto de *Fundamentos de Ingeniería de Software* (TESH, Semestre 5).

Mismo proyecto, distinta vibra: elegante, suave y personal.

## ✨ Detalles de esta versión

- Paleta rosa / lila / dorado con glassmorphism
- Tipografía serif *Cormorant Garamond* + *Poppins*
- Canvas de **destellos** (partículas que suben con brillo)
- Orbes de color difuminados que flotan
- Tarjeta personal con dedicatoria
- Línea de tiempo del proyecto estilo "camino"
- Sección especial destacada para Jazmín (QA)
- Contadores animados y reveal on scroll
- 100% responsive

## 🚀 Ver la página

Abre `index.html` en cualquier navegador. No requiere servidor ni dependencias.

## 🌐 Publicar en GitHub Pages

1. Sube esta carpeta a un repositorio de GitHub.
2. **Settings → Pages**.
3. Source: **Deploy from a branch** → `main` → `/ (root)`.
4. Guarda. Quedará en `https://<usuario>.github.io/<repo>/`.
